# blueprint-svgs

A collection of high-quality blueprint-style SVGs, free for any use.

Right now it's just aircraft. More categories may show up over time.

## Usage

Everything here is [CC0](LICENSE) — public domain. Use it for whatever you want, commercial or not. No attribution needed (though it's always appreciated).

The SVGs are drawn to be clean and scalable: open them in any vector editor, recolor them, trace them, print them on a poster. What ever you want.

## Structure

Each blueprint lives in its own folder, grouped by category. Every folder contains the SVG itself, a PNG preview, and a readme file with details about the subject and the drawing.

```
aircraft/
  boeing-777/
    boeing-777.svg
    preview.png
    readme.md
```

## Contributing

Found an error, or want to add a blueprint of your own? Issues and pull requests are welcome. Just keep in mind that anything merged becomes CC0 like the rest of the repo.
